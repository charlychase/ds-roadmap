# DS Roadmap

Proyecto de análisis de datos y desarrollo de funciones reutilizables de calidad de datos.

## Estructura del proyecto
- `data/`: Archivos de datos locales (no incluidos en el repositorio).
- `notebooks/`: Cuadernos de Jupyter con análisis exploratorios.
- `src/`: Código fuente y funciones reutilizables (como `data_quality_report.py`).
